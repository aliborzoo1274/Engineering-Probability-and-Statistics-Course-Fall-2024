# Engineering Probability and Statistics Course - Fall 2024

This repository contains assignments and projects for the Engineering Probability and Statistics course taken in Fall 2024 semester at University of Tehran. The coursework focuses on applying statistical concepts and probability theory through practical programming assignments using Python and Jupyter Notebooks.

## 📚 Course Overview

The course covers fundamental concepts in probability theory and statistics with a strong emphasis on computational implementations and data analysis using Python libraries such as NumPy, Pandas, and Matplotlib.

## 🚀 Getting Started

### Prerequisites

Install required Python packages: 

```bash
pip install numpy pandas matplotlib seaborn scipy jupyter
```

### Running the Notebooks

1. Clone this repository: 
```bash
git clone https://github.com/aliborzoo1274/Engineering-Probability-and-Statistics-Course-Fall-2024.git
cd Engineering-Probability-and-Statistics-Course-Fall-2024
```

2. Launch Jupyter Notebook:
```bash
jupyter notebook
```

3. Navigate to the desired assignment folder and open the `.ipynb` files

## 📖 How to Use This Repository

1. Each assignment folder (CA0-CA3) contains a PDF file with the problem statements and requirements
2. Solutions are implemented in Jupyter Notebooks within numbered subdirectories
3. Data files are included where necessary (e.g., `CA0/3/emails.csv`, `CA2/data/`)
4. Refer to the PDF files for detailed problem descriptions and grading criteria
